# Crochet Studio Website - Project Planning (v1.1)

---

# Project Name

**Nevo**

Premium Crochet & Handmade Knitting Showcase

**Slogan**: Made slowly. Kept forever.

---

# Goal

Create a premium, modern, beautifully animated website with a simple CMS that helps a crochet business:

* Showcase handmade work with stunning 3D visuals and animations
* Manage portfolio projects (add/edit/delete via admin panel)
* Manage media gallery
* Let visitors collect gallery items in a cart before sending an inquiry
* Capture leads and track inquiries
* Gain customer trust through design excellence
* Drive inquiries via WhatsApp and contact form
* Serve as a digital business card, portfolio, and content management hub

**Focus**: Beautiful showcase with 3D elements, a gallery cart for inquiry requests, and a functional CMS for easy management. Online payment and checkout are out of scope for the current phase.

---

# Technology Stack

## Frontend

* Next.js 15
* React 19
* TypeScript
* TailwindCSS
* Framer Motion (smooth animations)
* Three.js (lightweight 3D elements)
* React Three Fiber (3D component library)
* Drei (3D helpers)
* React Hook Form
* Swiper.js (image galleries)

---

## Backend

**Supabase (Recommended for free tier)**
* PostgreSQL database
* Real-time subscriptions
* Authentication
* Storage for images
* Edge Functions for serverless logic

---

## Database

**Supabase PostgreSQL**

Tables:
- Projects/Gallery Items
- Testimonials
- Orders/Inquiries
- Admin Users
- Messages
- Settings

The current phase stores inquiry/cart details only. Order tracking fields and workflows are reserved for a future phase.

---

## Storage

Supabase Storage

Later: Cloudinary for advanced image optimization

---

## Deployment

**Vercel** (Next.js frontend) - free tier

**Supabase** (database & backend) - free tier

Both have generous free tiers perfect for small projects

# Project Architecture

```
Client (Browser)
      |
      +-- Public Pages (Landing, Gallery, Work Details, Cart)
      |
      +-- Inquiry Request (Contact Form / WhatsApp)
      |
      +-- Admin Dashboard (Login Required)
            |
            v
      Next.js Frontend
            |
      REST API / Real-time Subscriptions
            |
      Supabase Backend
            |
            +-- PostgreSQL Database
            +-- Authentication
            +-- File Storage
```

**Scalable, real-time, and ready for future order tracking.**

# Animation System

Entrance animations (fade, slide)

Scroll animations (fade on scroll)

Page transitions (smooth)

Hover interactions (card lift, scale) - touch-friendly on mobile

**3D Elements:**
* Animated 3D objects in hero (yarn, hook, flower, etc.)
* 3D gallery card hover effects
* Subtle 3D parallax on scroll
* Touch-optimized interactions (no mouse tracking)

Smooth scrolling

**Mobile-first approach** - responsive animations that work on all screen sizes
