# Crochet Studio Website — Project Planning (v1.0)

---

# Project Name

**Nevo**

Premium Crochet & Handmade Knitting Showcase

---

# Goal

Create a premium, modern, beautifully animated website with a simple CMS that helps a crochet business:

* Showcase handmade work with stunning 3D visuals and animations
* Manage portfolio projects (add/edit/delete via admin panel)
* Manage media gallery
* Capture leads and track inquiries
* Gain customer trust through design excellence
* Drive inquiries via WhatsApp and contact form
* Track customer orders and inquiries
* Serve as a digital business card, portfolio, and content management hub

**Focus**: Beautiful showcase with 3D elements + functional CMS for easy management (no payment system needed).

---

# Technology Stack

## Frontend

* Next.js 15
* React 19
* TypeScript
* TailwindCSS
* Framer Motion (smooth animations)
* Three.js (lightweight 3D elements)
* React Three Fiber (3D component library)
* Drei (3D helpers)
* React Hook Form
* Swiper.js (image galleries)

---

## Backend

**Supabase (Recommended for free tier)**
* PostgreSQL database
* Real-time subscriptions
* Authentication
* Storage for images
* Edge Functions for serverless logic
